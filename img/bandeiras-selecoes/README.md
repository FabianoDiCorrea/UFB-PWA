# Bandeiras das seleções

218 arquivos SVG locais associados ao catálogo de seleções por código de associação. As bandeiras são servidas localmente pelo aplicativo; nenhuma requisição externa é feita durante as partidas.

Fonte: FlagCDN, cuja documentação informa que os ícones são da coleção `lipis/flag-icons`: https://flagcdn.io/docs/ e https://github.com/lipis/flag-icons. A coleção declara licença MIT; a licença e o aviso de copyright estão neste diretório.

Os códigos especiais das associações britânicas (`gb-eng`, `gb-nir`, `gb-sct`, `gb-wls`) e do Kosovo (`xk`) representam bandeiras de uso corrente no catálogo; não são logotipos de federações. A bandeira nunca é usada como escudo da federação.
